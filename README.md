# Random Password Generator

A simple password generator that creates random passwords using JavaScript.

## Features

- Generate random passwords
- Choose password length
- Use different character types
- Simple and responsive interface

## Technologies

- HTML
- CSS
- JavaScript

## Purpose

This project was built to practice JavaScript functions, randomization, strings, and application logic.
